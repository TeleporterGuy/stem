# Tools

← [Stem guide](../../README.md)

Open **Tools** and choose:

- [MCP servers](mcp-servers.md) — connected external tools, such as email, a database, or another app.
- [Skills](skills.md) — reusable procedures Stem can follow again.

A connection changes what Stem can do. A skill records how to do it.
